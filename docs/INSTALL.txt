ATM10A 0.7.1 简体中文适配 r2

Linux 云端服务端请下载单独的 server-linux-r2.1 包，执行 sh install.sh "服务端目录"。
支持 --check 检查和 --restore 还原；需要 Python 3.8+。详见 docs/LINUX.md。
以下 BAT 说明适用于 Windows。

客户端：退出游戏，解压 client ZIP，双击“双击安装-Windows.bat”，输入含 mods 和 config 的游戏目录。
服务端：关服，解压 server ZIP，运行同名 BAT，输入含 mods 和 server.properties 的服务端目录。
也可把整个解压文件夹放进实例根目录，让 BAT 自动识别父目录。
不要只复制 BAT，不要手动覆盖 payload。无需管理员权限或 Python。
仅检查-Windows.bat 会完成兼容检查但不写入游戏目录。

撤销：退出游戏／服务器后，运行“还原汉化-Windows.bat”。
备份位于实例根目录 .atm10a-zh-r2-backups，独立于 r1 的备份。
从 r1 安装到 r2 后，撤销 r2 会回到 r1；再使用原来的 r1 安装器还原 r1。
安装器遇到不同版本或被手动修改的脚本／数据会停止，不直接覆盖自定义内容。
重复安装 r2 无需再次写入。安装后被修改的文件会阻止还原，避免覆盖后续改动。
游戏改写过 options.txt 时，撤销只调整本包语言和资源包选择，保留其他设置。

两端使用同一份任务、蜜蜂、法术书数据译文与 RFTools/McJty 定向补丁。
客户端也包含这些服务端显示文本，供单人模式使用；专用服务器请使用 server 包。
字节码补丁仅处理选定的 10 个模块，未声称覆盖整合包全部硬编码文字。
任务编号、解锁关系、配方材料、法术组成和其他非显示数据均保持原值。
法术书数据和上游脚本在本地从你安装的原文件生成；此包不分发其完整定义或代码。

VaultPatcher 使用官方 1.5.3-fix-all，原始 JAR 校验值与对应源码在 third_party 中。
与基础 ATM10 r27 所带的改版 JAR不同：本包仅用类定向静态替换，并执行了官方转换器离线测试。
安装会备份并替换原 mods/vaultpatcher.jar；不要同时安装其他文件名的 VaultPatcher JAR。
蜜蜂显示名迁移会写入存档中的名字字段；文件还原不能撤销已保存的世界数据，服主应保留存档备份。

验收范围：静态校验、实际字节码转换器离线验证、Windows 安装／还原测试。
按用户要求未启动正在使用的客户端，也未连接云端服务器；未进行真实开服或多人联机测试。
请先在自己的测试实例中确认日志和界面，再使用于长期存档。
