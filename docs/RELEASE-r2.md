适配 ATM10: Aeronautics **0.7.1**（Minecraft 1.21.1 / NeoForge 21.1.250）。

- 客户端补齐 10 个 RFTools / McJty 定向汉化模块，与服务端共用修正版。
- 补回 2 处任务插图；修正 27 条无法生效的拼接文本匹配，清理过时和重复项。
- 449 条有效补丁全部通过实际 VaultPatcher 转换器离线验证。
- 保持 73 个任务文件、8,447 个字段；65 个数据文件只改显示文本。
- Windows BAT 安装器提供版本与文件校验、备份、还原及重复安装保护。

下载 `client` ZIP 用于客户端，`server` ZIP 用于专用服务端。解压后双击「双击安装-Windows.bat」。不要下载 GitHub 的 Source code ZIP 当作安装包，也不要直接覆盖 payload。

本版本通过离线转换与 Windows 安装／还原测试，**未进行真实开服、客户端启动或多人联机验证**，因此标记为预发布。安装前完全退出游戏／关闭服务器，保留存档备份。只支持目标 0.7.1，不承诺覆盖每个模组的全部英文。
