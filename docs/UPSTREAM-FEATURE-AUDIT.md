# 原 ATM10 汉化包功能对照

对照基准：ATM10 r27-beta1 / ATM10 8.2；目标：ATM10A 0.7.1。此次对照确认此前遗漏了原包的可选拼音搜索。以下是文件与安装逻辑审计，不是游戏内验收，也不是全部模组翻译覆盖率。

| 项目 | 当前状态 |
| --- | --- |
| 可选拼音搜索 | 已补回原包相同的 Just Enough Characters 4.5.29，JAR SHA-256 一致，提供独立 Windows 安装、检查、卸载入口。已有模组会跳过，包含改名后的同 modId 模组。 |
| 资源包、手册、任务译文 | 已迁移并补译航空版任务与附属模组；具体范围见 README 和 reports。未逐个游戏界面验收。 |
| 字节码硬编码翻译 | 原包 modules 目录含 159 个模块，当前选用 10 个并验证 449 条匹配。剩余模块尚未逐一适配；不能把 10 个模块验证通过解释为保留了全部原包补丁。模块数量不等于缺少体验数量。 |
| 汉化资源包未启用／覆盖顺序提醒 | 原包 hanhua_pack_check.js 尚未迁移。当前安装器会启用资源包，但没有原包的游戏内提醒功能。 |
| 原包更新检查 | hanhua_update_check.js 尚未迁移。原包更新地址对应 ATM10，不能直接用于 ATM10A；当前通过本仓库 Releases 手动更新。 |
| 附加提示脚本 | occultism_flame_tooltip.js、pb_hanhua_tooltip.js、pb_hanhua_tooltip_actions.js 尚未迁移，需另行确认航空版 API、目标条目和兼容性。 |
| Mystical Customization 显示配置 | 原包自定义作物／等级配置尚未逐项核对迁移；不能用整体覆盖方式替换航空版玩法配置。 |
| 主菜单图片及链接 | 迁移了部分汉化图片，未照搬原包所有图片、作者链接和广告布局，沿用航空版菜单结构。 |
| ATM10 专属多方块／玩法脚本 | 目标整合包不同，未整体覆盖；需按航空版实际存在的功能判断适用性。 |
| 安装与还原 | 当前 Windows 安装器和 Linux 服务端安装器独立实现；拼音补装器使用独立记录，保留汉化备份和用户设置。 |

拼音补装器已在 Windows PowerShell 5.1 的临时实例中通过 9 项检查，见 [报告](../reports/pinyin-verification.json)。未启动 Minecraft，不能据此声称所有搜索框已通过实际兼容验证。此次发布补齐拼音组件，以上其余未迁移项仍然待办。
